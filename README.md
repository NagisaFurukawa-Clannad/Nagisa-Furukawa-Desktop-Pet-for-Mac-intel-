# -for-Mac-intel-
给Mac intel芯片用的古河渚桌宠，需自备DeepSeek的API密钥
鼠标右键单击古河渚，选择设置Deepseek API Key，输入API，建议新开一个API，只充2～3RMB就够了
#API Key属于高度隐私,所以是保存在钥匙串里的；每次重启都要输入密码！！！
